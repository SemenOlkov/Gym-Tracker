# Gym Tracker — Ваш персональный дневник тренировок

**Gym Tracker** — это современное Android-приложение для тех, кто хочет детально отслеживать свой прогресс в тренажёрном зале. Приложение ориентировано на функциональность, минимализм и работу в режиме офлайн.

---

## 🚀 История обновлений (v3.0.0)

### ⚖️ Поддержка единиц измерения (КГ / LB)
- **Двойное хранение**: Теперь приложение одновременно сохраняет вес в килограммах и фунтах. Это гарантирует отсутствие потерь точности при переключении единиц.
- **Мгновенная конвертация**: Вся ваша история тренировок и замеров веса тела автоматически пересчитывается при смене системы мер в настройках.
- **Высокая точность**: Все веса теперь отображаются с точностью до двух знаков после запятой (0.00).

### 🍎 Питание и КБЖУ
- **Дневник питания**: Полный контроль калорий, белков, жиров и углеводов.
- **База продуктов**: Создание собственных продуктов и быстрый поиск по истории.
- **Аналитика питания**: 4 интерактивных графика для отслеживания динамики потребления нутриентов за неделю, месяц или год.

### 📊 Продвинутая аналитика и графики
- **Временная шкала**: На всех графиках (прогресс в упражнениях, вес тела, питание) по оси X теперь отображаются реальные даты вместо порядковых номеров.
- **Детализация**: Улучшенные графики 1RM (одноповторного максимума) и тренировочного объема.
- **Интерактивность**: Поддержка маркеров и зума для детального изучения точек прогресса.

### 🧭 Навигация и Интерфейс
- **Боковое меню (Drawer)**: Второстепенные разделы (Настройки, Бэкап, О приложении) вынесены в боковую панель, освободив место в нижнем меню для ключевых функций.
- **Dynamic Colors (Material You)**: Поддержка динамических тем оформления на основе обоев вашего устройства (для Android 12+).
- **Темная и светлая темы**: Полноценная поддержка различных режимов отображения.

### 🛡️ Безопасность и Сохранность данных
- **Защита истории**: Завершенные тренировки защищены от случайного удаления.
- **Подтверждение действий**: Добавлены диалоги подтверждения для всех операций удаления (упражнения, замеры, продукты).
- **JSON Backup**: Система резервного копирования и восстановления всех данных в открытом формате.

## Основные возможности

### 📋 Управление тренировками
- Создание тренировок с произвольными названиями.
- Контролируемый процесс выполнения: каждый подход подтверждается отдельно.
- Блокировка редактирования после завершения тренировки для сохранения чистоты данных.
- Визуальная индикация завершенных тренировок в общем списке.

### 🧠 Интеллектуальные рекомендации
- Система автоматически анализирует ваши последние успехи и предлагает рабочий вес для следующей тренировки.
- Алгоритм учитывает типы прогрессии (на увеличение веса или на уменьшение, как в гравитроне).
- Специальная логика для монолатеральных упражнений.

### 🏋️ База упражнений
- Более 20 предустановленных упражнений с подробными инструкциями и указанием целевых групп мышц.
- Возможность создания собственных упражнений с настройкой типа прогрессии, монолатеральности и количества снарядов.

### ⏱️ Удобство в зале
- **Настраиваемый таймер отдыха**: Автоматический запуск обратного отсчета после каждого подхода.
- **Заметки**: Возможность оставлять текстовые комментарии к каждому подходу.

## Технологический стек
- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **База данных:** Room (SQLite)
- **Настройки:** Jetpack DataStore
- **Архитектура:** MVVM + Clean Architecture
- **DI:** Dagger Hilt
- **Графики:** Vico Charts

# Gym Tracker — Ваш персональный дневник тренировок

**Gym Tracker** — это современное Android-приложение для тех, кто хочет детально отслеживать свой прогресс в тренажёрном зале. Приложение ориентировано на функциональность, минимализм и работу в режиме офлайн.

## Основные возможности

### 📋 Управление тренировками
- Создание тренировок с произвольными названиями.
- Контролируемый процесс выполнения: каждый подход подтверждается отдельно.
- Блокировка редактирования после завершения тренировки для сохранения чистоты данных.
- Визуальная индикация завершенных тренировок в общем списке.

### 🧠 Интеллектуальные рекомендации
- Система автоматически анализирует ваши последние успехи и предлагает рабочий вес для следующей тренировки.
- Алгоритм учитывает типы прогрессии (на увеличение веса или на уменьшение, как в гравитроне).
- Специальная логика для монолатеральных упражнений.

### 📊 Продвинутая статистика и аналитика
- **Личные рекорды (PR):** Отслеживание максимального веса для каждого упражнения с фиксацией даты.
- **Объем тренировки:** Автоматический расчет суммарного тоннажа.
- **Расчет 1ПМ (One-Rep Max):** Прогноз максимального веса на одно повторение по формуле Эпли.
- **Интерактивные графики:** Наглядная визуализация прогресса (макс. вес, объем) с поддержкой маркеров при нажатии.
- **Раздельные графики:** Для упражнений на одну сторону (лево/право) строятся независимые графики.

### 🏋️ База упражнений
- Более 20 предустановленных упражнений с подробными инструкциями и указанием целевых групп мышц.
- Возможность создания собственных упражнений с настройкой типа прогрессии и монолатеральности.

### ⚖️ Контроль веса тела
- Отдельный раздел для фиксации веса.
- История взвешиваний с интерактивным графиком изменений.

### ⏱️ Удобство в зале
- **Таймер отдыха:** Автоматический запуск обратного отсчета (3 минуты) после каждого выполненного подхода.
- **Заметки:** Возможность оставлять текстовые комментарии к каждому подходу.
- **Оптимизированный ввод:** Удобная работа с десятичными значениями веса без лишних прыжков курсора.

## Технологический стек

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **База данных:** Room (SQLite)
- **Архитектура:** MVVM + Clean Architecture (UseCases)
- **DI:** Dagger Hilt
- **Графики:** Vico Charts

## Дизайн
Приложение выполнено в премиальной темной теме **"Midnight & Lime"**:
- Глубокий черный фон для экономии энергии и комфорта в залах с любым освещением.
- Неоновые акценты для быстрой навигации и выделения важных достижений.
- Крупная типографика для отличной читаемости «на расстоянии вытянутой руки».
